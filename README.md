# Beauty Research — 美容コンテンツ横断リサーチ

TikTok・YouTube・XのURLと投稿情報、ローカルMP4、分析メモ、投稿間の関係をまとめる日本語Streamlitアプリです。TikTokの公開情報取得は公式oEmbedを利用します。APIキーと利用料金は不要です。AI接続はありません。

## 起動方法

Python 3.12とffmpeg（ffprobeを含む）が必要です。Ubuntuの場合、ffmpeg未導入なら `sudo apt-get update` と `sudo apt-get install ffmpeg` で導入できます。

```bash
cd /workspace/tiktok-analyzer
python -m venv .venv
.venv/bin/pip install -r requirements-lock.txt
.venv/bin/python -m streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

このクラウド環境では導入済みです。停止するには起動したターミナルでCtrl+Cを押します。自分のPCではリポジトリを保存した場所に読み替えてください。Windowsの仮想環境は `.venv\Scripts\python.exe` を使用します。

## 使い方

1. TikTokは「登録」上部に動画URLを貼り、「TikTokの公開情報を取得」を押します。公式oEmbedが返した説明文・投稿者名を表示し、内容を確認して保存できます。項目が返らなければ未取得と表示します。公式プレーヤー情報だけが返る動画にも対応し、チェックするとブラウザからTikTokのプレーヤーを読み込みます（再生可否は別途確認が必要）。短縮URLは未対応で、追跡パラメーターは除去します。YouTube・Xなどは下の手動登録フォームを使います。
2. MP4を選ぶと長さと0・1・2秒の静止画を抽出。SNSの登録にもMP4を添付できます。MP4だけなら「ローカル動画」を選びます。
3. 「検索・閲覧」で登録情報・動画・フレームを確認。サイドバーで本文、タグ、メモなどを検索できます。
4. 「分析メモ」で冒頭3秒、カット割り、テロップ、音声、商品紹介、CTA、成功パターン、企画案を手動記録します。
5. 「投稿の関係」で登録済みの2件を選び、リプライ・引用・宣伝リンク・販売導線などの方向と根拠を保存します。
6. 「比較・CSV出力」で最大4件を横並びに比較し、登録情報・メモ・関係をCSVで出力します。現在の検索条件が反映されます。

## 確認状態と未取得データ

- **未取得**：まだ情報がない状態。値をゼロや事実として補完しません。
- **ユーザー入力**：手動登録した情報。サービス側での検証を意味しません。
- **確認済み**：ユーザーが根拠を添えて確認したメモ。システムによる真偽保証ではありません。
- **推測**：仮説や企画案。根拠のある事実と区別します。

動画の長さと静止画は「ローカル抽出」、TikTokの説明文・投稿者名は公式oEmbedの取得元と取得時刻を表示し、それ以外のSNSメタデータは「未取得」、AI解析は「未実施」と表示します。CSVにも出所・メモの状態・根拠・未取得状態が含まれます。Xの関係はユーザーが入力した調査記録であり、不正・組織的宣伝を判定する機能はありません。

## 保存場所・注意点

- 初期保存先は `data/research.sqlite3` と `data/videos/`。`RESEARCH_DATA_DIR` 環境変数で変更可能です。
- 動画はブラウザから**このアプリのサーバー**にアップロードして保存します。AIには送信しません。TikTokの取得ボタンを押すと、追跡パラメーターを除いた動画URLをTikTok公式oEmbedへ送信します。動画ファイルは送信しません。Streamlitの利用統計は無効です。
- `data/`、仮想環境、APIキー用ファイルはGit管理対象外です。個人情報は必要な範囲だけ登録してください。
- 認証・利用者別データ分離は未実装です。信頼できる利用者のみがアクセスする環境で使用してください。一般公開サービス向けの構成ではありません。
- 最大200MBのMP4。対応コーデックは環境のffmpegに依存します。3秒未満は存在する秒数のみ抽出。エラー時は途中ファイルを削除します。
- バックアップはアプリを停止して**dataフォルダー全体**をコピーしてください。CSVは調査結果の出力用で、動画を含む完全バックアップではありません。現段階の動画パスは絶対パスのため、復元先も同じパスにしてください。
- 編集・削除・CSVインポートは未実装です。

## テスト

```bash
.venv/bin/python -m pytest python_tests -q
```

SQLite永続化、検索、関係、出典必須ルール、URL検証、CSV数式対策、実MP4抽出、破損ファイルの後片付け、Streamlit画面での登録→メモ→比較を検証します。

以前のブラウザ内MP4プレビュー（`src/`、`index.html`）も保持しています。そちらは `npm ci && npm run dev` で動作しますが、SQLite保存はありません。本アプリの通常起動はStreamlitです。

## TikTok取得機能の検証範囲

公開情報取得の正常・HTTPエラー・タイムアウト・不正応答・保存・画面操作はモック応答で検証しています。当初はプロキシ403で接続できませんでしたが、その後、対象URLの公式oEmbedとの実接続を確認しました。この動画はHTTP 200でも説明文・投稿者名を含まず、公式プレーヤー情報だけを返しました。動画本体の取得・再生は未確認です。公開先でも取得が保証されるわけではありません。アクセス制限の回避は行いません。動画本体・フレーム・音声・テロップ・再生数は取得せず、AI解析も実施しません。説明文にある商品名なども投稿者の記載であり、映像を確認した事実とは区別してください。
